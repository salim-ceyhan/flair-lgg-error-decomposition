# flair-lgg-error-decomposition

Reference implementation for:

> **Decomposing the error into localization, boundary representability and
> selection in training-free single-FLAIR lower-grade glioma segmentation**
> Salim Ceyhan, Bilecik Şeyh Edebali University.

The pipeline uses **no learned weights and no labels** at any stage. Ground truth
is confined to the *measurement plane*: it is used for evaluation, for the
attainable-ceiling computation and for the error decomposition, and it never
enters the pipeline.

## What this repository contains

The canonical Stage-1 pipeline and the runners that produce the paper's main
numbers:

| Path | Role |
|---|---|
| `src/candidate_selection.py` | Stable public entry point — import through this |
| `pipeline/probe_realmask_seed.py` | Constants, NewMetric front end, score map, quality criterion |
| `pipeline/probe_persistence.py` | Candidate generation, plateau persistence, selection |
| `pipeline/brain_roi_tcga.py` | Gated brain-ROI extraction for raw, skull-bearing FLAIR |
| `src/segmentation_metrics.py` | Dice / Jaccard / sensitivity / precision |
| `facseg/` | Vendored NewMetric backend — see *NewMetric backend* below |
| `evaluation/` | Runners for the reported experiments |

Evaluation runners:

| Script | Produces |
|---|---|
| `eval_full_metrics_roi.py` | Full metric package for the gated brain-ROI method |
| `evaluate_lbs_error_decomposition.py` | Localization–boundary–selection decomposition |
| `evaluate_channel_ablation.py` | Per-channel ablation of the two generation arms |
| `evaluate_candidate_ceiling_saturation.py` | Nested seed / α budget saturation |
| `evaluate_constant_sensitivity.py` | Sensitivity sweep of the canonical constants |
| `validate_ucsf_lower_grade.py` | Frozen-pipeline UCSF-PDGM grade 2–3 validation |
| `build_frozen_candidate_pool.py` | Frozen candidate pool used by the analyses |
| `materialize_dataset_cache.py` | One-time local dataset cache |

## What it does not contain

- **No datasets.** TCGA-LGG, UCSF-PDGM and BraTS 2023 are obtained from their own
  distribution channels; nothing derived from them is committed.
- **No result caches.** The per-case CSV/JSON outputs referenced by the paper are
  regenerated by the runners above.
- **No supervised re-ranker.** The learned selection layer is outside the scope of
  this paper and is reported separately.

## Install

```bash
python -m venv .venv && . .venv/bin/activate   # Windows: .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Verify that the pipeline and its NewMetric backend resolve:

```bash
python -c "import sys; sys.path.insert(0,'src'); import candidate_selection as c; print(c.pipeline.NEWMETRIC_BACKEND)"
```

Expected output: `facseg-fast`.

## Data

Point `FINSLER_DATA_ROOT` at a directory containing `tcga_lgg_dataset/`, in which
each case is a folder holding `flair.npy` and `mask.npy`:

```bash
export FINSLER_DATA_ROOT=/path/to/data      # Windows: $env:FINSLER_DATA_ROOT="D:\data"
```

The input is, per patient, the single axial FLAIR slice with the largest tumour
area; the target is the whole tumour. `materialize_dataset_cache.py` applies that
same largest-slice rule to a source tree and validates case and array counts
before marking the cache ready.

For the external cohort, set `UCSF_PDGM_PROCESSED` to the processed UCSF-PDGM
directory.

## NewMetric backend

The edge-preserving front end is `NewMetric`, from the filter family of

> H. Kılıç, S. Ceyhan, O. N. Gerek, "A novel family of edge preserving anisotropic
> filters," *Digital Signal Processing*, vol. 128, art. 103623, 2022.
> doi: <https://doi.org/10.1016/j.dsp.2022.103623>

The required modules are vendored under `facseg/src/facseg/` so that this
repository runs standalone. `pipeline/probe_realmask_seed.py` discovers them
automatically; `FACSEG_ROOT` overrides the search if you want to point at a
separate checkout.

**A CPU fallback is deliberately not provided.** It would not be numerically
equivalent to `facseg.newmetric_fast`, and results produced with a substitute
front end are not comparable to the reported numbers.

> **Licensing note.** The vendored `facseg` modules originate from a separate,
> co-authored codebase that carries no license file of its own. Their terms must
> be settled with the co-authors before this repository is made public.

## Interpreting the numbers

Three cautions are load-bearing and are stated the same way in the paper:

- **TCGA-LGG is a development set, not an independent test set.** Slices were
  selected by ground-truth tumour area, and ground truth was used for method
  development, hyperparameter selection and error analysis. The frozen pipeline's
  UCSF-PDGM result is the external one.
- **Oracle values are not inference performance.** They select retrospectively
  against ground truth and measure the *attainable ceiling* of candidate
  generation.
- **BraTS 2023 is a cross-grade stress test**, not lower-grade validation: it is a
  predominantly high-grade, skull-stripped regime.

Canonical label-free delivery on the TCGA-LGG development set is **0.615** mean
all-case Dice, rising to **0.659** under gated brain-ROI renormalization
(zero-Dice cases 15 → 6). The gate opens only on raw, skull-bearing input; on
skull-stripped cohorts it never triggers.

The canonical raw-TCGA order is NewMetric diffusion **first**, then the gated ROI
re-normalization. A forced ROI-first order was re-evaluated on all 110 cases and
rejected (mean Dice 0.659 → 0.565 / 0.571).
